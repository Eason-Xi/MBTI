# 性格罗盘 · MBTI 性格测试

纯静态网站，无需构建，直接用浏览器打开 `index.html` 即可使用。

本地预览：

```bash
python3 -m http.server 5173
```

## 目录结构

- `index.html`：页面结构（首页 / 答题 / 结果 / 16 种类型）
- `css/style.css`：样式，支持深色模式与移动端
- `js/questions.js`：题库，48 题，每个维度 12 题（正反向各 6 题）
- `js/types.js`：16 种类型、四个类型组与维度说明
- `js/app.js`：答题流程、计分、路由与进度保存

## 计分方式

每题 7 级量表，对应 -3 ~ +3 分，按题目方向累加到所属维度，
换算为左侧字母（E / S / T / J）的百分比，≥ 50% 取左侧字母。

结果通过网址 hash 保存（如 `#result=INTJ-30-20-75-68`），可直接分享。
